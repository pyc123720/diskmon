diskmon 磁盘监测 v1.4.1（Windows 10/11 x64）
================================================

一个托盘常驻的小工具：看 C 盘为什么变少、谁在写、能清什么，清理可撤销。
只读监测，不会主动删文件（清理动作都要你点确认，且能在看板里一键撤销）。

一、两种用法，选一个就行
------------------------
A. 安装版（推荐）：
   双击 diskmon-setup.exe → 若弹 UAC 点「是」→ 按提示点「是」。
   装完托盘出现图标，桌面多一个「磁盘监测」快捷方式，开机自动启动。
   卸载：再运行一次 diskmon-setup.exe 选卸载，或「设置 → 应用 → 已安装的应用」里卸载。

B. 绿色版（不想装）：
   把 diskmon-go.exe 放到任意文件夹，双击运行即可（托盘）。
   数据写在 exe 同级的 data\ 文件夹，删掉文件夹就干净了。

二、第一次用
------------
1. 托盘图标：左键 = 打开看板（浏览器 127.0.0.1:8766），右键 = 菜单。
2. 看板后点一次「扫描」，等 1–2 分钟（只读，不会改任何文件）。
3. 然后看「懒人清理」，清理完不满意可以一键撤销。

三、如果 Windows 拦你（很可能发生）
----------------------------------
这个程序是个人自编译、自签名的，没有花钱买商业证书，所以：

- 出现「Windows 已保护你的电脑」（SmartScreen）
  → 点「更多信息」→「仍要运行」。
- 被杀毒/安全软件报「未知程序 / 潜在垃圾软件」
  → 加白名单，或直接用绿色版、把 diskmon-go.exe 所在目录加入排除。
- 安装时显示「未知发布者」
  → 正常。安装器可选择把随包的 diskmon-codesign.cer 导入「受信任的发布者」，
     导入后本机就不再提示；不导入也能正常用。

我不联网、不上传任何数据，没有网络请求，只有本机 127.0.0.1:8766 的看板。

四、包里的文件
--------------
diskmon-setup.exe        安装器（约 11 MB，内含主程序）
diskmon-go.exe           绿色版主程序（约 8 MB）
README.md                完整说明（功能、原理、命令行参数、数据目录）
diskmon-codesign.cer     自签名证书（可选导入）
SHA256SUMS.txt           校验值，可用 certutil -hashfile <文件> SHA256 对比

五、已知限制
------------
- 只盯一个盘（默认 C:），其它盘请在设置页改。
- 「秒级归因」（谁在一秒内写了多少）需要管理员权限；非管理员会自动降级成
  定时重扫模式，功能仍在，只是精度差一些。
- 清理动作默认只动临时文件/缓存，跳过文档、桌面、图片、.git、.ssh 等目录。
